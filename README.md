# Ôn giữa kỳ Tiếng Anh 6

Trang web ôn tập giữa kỳ môn Tiếng Anh 6 (Global Success, Unit 1–3), gồm: Từ vựng, Ngữ pháp, Làm bài, Đề cương 1 và Đề cương 2.

## Cách đưa lên GitHub Pages
1. Tạo repository mới trên GitHub (ví dụ: `on-giua-ky-tieng-anh-6`), chọn Public.
2. Giải nén file ZIP, vào repository bấm **Add file → Upload files**, kéo thả toàn bộ file (index.html, .nojekyll, README.md) rồi **Commit changes**.
3. Vào **Settings → Pages**, mục *Build and deployment* chọn **Deploy from a branch**, Branch: `main`, thư mục `/ (root)` → **Save**.
4. Chờ 1–2 phút, link sẽ có dạng: `https://TEN-TAI-KHOAN.github.io/on-giua-ky-tieng-anh-6/`
